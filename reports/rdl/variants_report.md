# RDL 與各種變體的整理：哪些真的有用

## 先說明：五類分數不是官方分數

官方規則（README 第 4 節）：測試週 GH Archive 缺哪個活動，該活動不計分。本機資料約一半小時看不到 push，所以我額外算了「排除 push」的五類分數做診斷。**提交檔仍預測六欄，官方實際算幾類要等測試週資料決定**，因此表中同時列五類與六類，兩者排序不完全一致（例如統計 v2 在五類持平、六類低 1.9）。下文結論若只在五類成立，會另外標明。

## 結論

1. 對我們的任務，**關係與時間建模本身帶來的增益很小**：最好的變體（統計特徵＋事件序列）只比基準高 0.5 點（5 類），而同一組設定換 seed 就會有 0.5～1 點的波動。
2. **有用且兩年一致的只有三件事**：
   - 自監督預訓練：關掉會低 1.2 點（2026）。
   - 相對時間編碼：關掉會低 0.9（2026）、0.5（2025-12）。
   - 使用者近期統計特徵（預訓練後再加入）：+0.2（2026）、+1.0（2025-12）；統計＋序列 +0.5／+0.6。
3. **兩年一致沒用或有害**：編碼器微調（-1.4／-0.7）、額外外鍵邊（-1.0／-0.3）、取最新鄰居（-0.6／-0.4）、把統計特徵放進預訓練（-1.3，只在 2026 測）。
4. 2025-12 的結果排序與 2026 大致相同，所以去年資料可以當第二個驗證場；但 2025-12 上 GNN 只和 copy-last-week（5 類 50.4）、GBDT（49.3）同一水準，鑑別力有限。
5. **資料增強（隨機丟邊、遮蔽使用者事件邊）沒有幫助**：2026 低 0.8／1.2 點（丟邊率降到 0.1 並加到 GRU 階段也是 -0.8），2025-12 持平或略低（-0.3／0）。
6. **把事件先後放進圖（前一筆事件邊）與 focal loss 也沒有幫助**：先後邊 2026 -0.8、2025-12 -0.3；focal loss 2026 -0.4、2025-12 -0.9。
7. **GRU 的遞迴更新只有很小的貢獻**：拿掉狀態更新（保留逐日損失與位置向量）2026 低 0.7、2025-12 低 0.3，都在 seed 波動範圍內，所以只能說「略有幫助，證據不強」。
8. 報告可以誠實寫：RDL 讓我們不必手工合併表，而且預訓練和時間編碼各有約 1 點收益；但在這個資料量與標籤型態下，更複雜的關係建模（RelGNN、群組節點、額外邊）沒有帶來增益。

## 和 CNN／RNN／GNN 的差別

概念表與流程見 [part_concepts.md](part_concepts.md)，文獻整理見 [survey_rdl.md](survey_rdl.md)。一句話版：CNN 吃網格、RNN 吃單一序列、一般 GNN 吃一張同質圖；RDL 的輸入是**一個資料庫的多張表**，列是節點、外鍵是邊，並且每個預測都只能看切點之前的列。我們的 GRU 負責「這個使用者的 7 天」，RDL 的圖編碼器負責「這個使用者透過 repo、PR、issue 看到的世界」。

## 判定

| 問題 | 結果 | 判定 |
|---|---|---|
| 預訓練有用嗎？ | 不預訓練低 1.2；微調編碼器低 0.7～1.4 | 有用，且要凍結 |
| 時間資訊有用嗎？ | 關掉相對時間編碼低 0.9／0.5；取最新鄰居低 0.6／0.4 | 有用，均勻取樣＋相對時間編碼較好 |
| 加更多關係有用嗎？ | 額外邊 -1.0／-0.3；owner/org 節點 -0.6；RelGNN 約 -3 | 沒用 |
| 使用者自己的歷史有用嗎？ | 統計 +0.2／+1.0；統計＋序列 +0.5／+0.6；v2 特徵 0 | 小幅有用，序列單獨不夠 |
| 資料增強有用嗎？ | DropEdge 0.2：-0.8／-0.3（0.1＋GRU 階段：-0.8）；遮蔽使用者事件邊 0.3：-1.2／0.0 | 沒用；訓練切點已多、取樣本身有隨機性 |
| GRU 的遞迴更新有用嗎？ | 拿掉更新：-0.7／-0.3（六類 -1.0／-0.3）；兩年方向一致但幅度小 | 略有幫助，證據不強 |
| 事件先後放進圖有用嗎？ | 先後邊：-0.8／-0.3（六類 -0.4／-0.4） | 沒用；與事件序列編碼的結果一致 |
| 換損失有用嗎？ | focal loss γ=2：-0.4／-0.9 | 沒用，只試了 γ=2 |
| 圖的深度？ | 2 hop 與 3 hop 差 0.1 | 無差別 |
| 逐日標籤 vs 週標籤？ | 週標籤低 1.0 | 逐日較好 |

## 限制

- seed 標準差 0.5～1，小於 1 點的差異不能當證據。
- 2025-12 只有一個測試週（12/28 因資料範圍被丟掉）。
- hpre、gap 等少數變體 2025-12 沒測；RelGNN 只測了 2026 且 3 seeds。
- GRU 消融重用基準的預訓練編碼器，只重訓第二階段，所以不含預訓練的隨機性；週標籤頭那組仍混了切點數。
- 先後邊只連同一張表內的前後事件，不跨表；focal 只試 γ=2。
- 增強只試了丟棄率 0.1、0.2、0.3 三組，2025-12 沒測 0.1＋GRU 那組。
- RelGT 型 token 沒實作；文獻細節見 survey 的「未核對事項」。
